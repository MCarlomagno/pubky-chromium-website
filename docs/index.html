Before you install

01 / PLATFORM

Mac with Apple silicon

Built for macOS 13 or later. Tested on an M2 Pro with macOS 26.6.2; older macOS versions have not been tested. This package does not support Intel Macs.

02 / VALIDATION

Tested on a real Mac

148 focused unit tests and four capability test fixtures passed. Native checks covered ordinary HTTPS, a live public-key homeserver, wrong-key rejection and Metal graphics with the sandbox enabled.

03 / LIMITS

For experimentation

No automatic update channel. Keep your usual browser for daily use. Complete macOS first-launch prompts before browsing. Leaving the browser’s Safe Storage prompt pending can stall navigation and delay shutdown.

Install a separate test copy

  1. Verify the download. Compare the ZIP's SHA-256 with the value below using shasum -a 256 pubky-chromium-156.0.8073.0-macos-arm64.zip.
  2. Expand the ZIP. Keep its license notices. Rename Chromium.app to Pubky Chromium.app and move it into your user's Applications folder. Create that folder if needed; this avoids replacing another Chromium installation.
  3. Open with a separate profile. Run the command below in Terminal. This keeps test browsing separate from an existing Chromium profile.
  4. Review macOS's warning. This app has an ad-hoc signature, sealed resources, and no Developer ID or Apple notarization. If you trust the verified package, use System Settings → Privacy & Security → Open Anyway after the first opening attempt. macOS may require authentication. Follow Apple's instructions; keep Gatekeeper enabled. Managed Macs may prohibit this exception.
open -n "$HOME/Applications/Pubky Chromium.app" --args --user-data-dir="$HOME/Library/Application Support/Pubky Chromium"

The native tests used local copies. A quarantined copy showed the expected macOS warning and Open Anyway option; completion of that exception was not verified. If macOS asks for Chromium to access its own “Chromium Safe Storage” item, complete that system prompt to initialize encrypted local storage. To uninstall, quit the app and move your test app to the Trash. The separate profile stays in your Library; remove it only if you also want to erase its browsing data.
